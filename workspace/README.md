# Workspace 约定

`workspace/` 不是 Maven 模块，也不是产品发布物。它只承载 Atlas 在本机或部署环境中运行时需要的项目配置、生成快照、源码缓存和人工内容包。

可提交的内容：

- `atlas-workspace.example.yaml`：不含真实业务信息的配置模板；
- 与真实系统无关的格式说明或示例数据包。

不可提交的内容必须位于 `workspace/local/`，该目录已经被 Git 忽略。典型内容包括：实际被分析项目的绝对路径、私有 Maven 仓库地址、源码归档、运行态导出、访问令牌、真实业务说明和故障记录。

部署时应由环境变量、密钥管理系统或部署编排工具将私有配置注入 `workspace/local/`；Atlas 核心 Maven 工件不读取也不携带这些内容。
