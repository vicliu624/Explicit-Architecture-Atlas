# Security Policy

## Supported versions

Security fixes are applied to the latest released version on `main`. The initial supported release line is `0.0.x`.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's **Security** tab to create a private vulnerability report. Include the affected artifact and version, a minimal reproduction, the impact you observed, and any mitigation you have identified.

If private reporting is unavailable, contact the maintainer through the repository owner's GitHub profile and avoid including exploit details in a public issue.
